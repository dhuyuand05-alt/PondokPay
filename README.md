# PondokPay

Aplikasi pengelolaan saldo santri dan transaksi kantin, terdiri dari backend REST API dan frontend web.

## Struktur repository

- `backend/` — API Node.js/Express, integrasi MySQL, migrasi, dan operasi backup.
- `backend/sql/install.sql` — installer skema lengkap untuk database baru.
- `frontend/` — aplikasi web React/Vite.
